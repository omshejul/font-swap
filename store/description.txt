SwapFont lets you try different fonts on a live web page without changing its code. It is free and open source, made for designers and developers who want to compare typography on real content.

Click the toolbar icon and hover over text to see its CSS font name. Click a font, choose a replacement, and it applies immediately.

- Search Google Fonts, or pick another font already on the page.
- Add and edit pairs. Remove one swap or undo all.
- Filter swaps by HTML tags. Give the same source font different replacements with independent tag choices.
- Use floating controls or Chrome's side panel. Switching keeps active swaps.
- Remember main-page pairs and tag choices with optional site permission.
- Optional feedback opens an editable email draft. Nothing is sent automatically.

Search uses the last valid downloaded or bundled catalog. Opening SwapFont silently refreshes https://omshejul.com/api/swapfont/catalog after seven days since its last success, or on first use. Failed or interrupted attempts wait one hour. Refreshes never block picking, search or swaps. Nothing is scheduled while unused. Metadata and timestamps stay local.

No behavioral analytics. Catalog requests omit cookies and referrer and send no visited site URL, page text, search, selected font, settings or installation identifier. Vercel hosts the endpoint and processes IP addresses and HTTP metadata; it may derive approximate location or retain operational/security logs. Font downloads reveal the selected font and connection information to Google. All executable JavaScript is bundled; remote catalog JSON, stylesheets and fonts are data.

Chrome desktop 116+. Ordinary HTML text only. Images, canvas, PDFs, browser pages, the Chrome Web Store and inaccessible frames are unsupported. A glyph may use a fallback instead of the detected CSS family. Page-picked fonts must be available on the page. New downloads need a connection; cached fonts may work offline.
