# Side panel contract

Plain HTML/CSS/JavaScript. No inline scripts, remote JavaScript, or framework. UI files are extension/sidepanel.html, .css and .js.

Send {type:'PANEL',action,tabId,...payload} through chrome.runtime.sendMessage. Response is {ok:true,state?,catalog?} or {ok:false,error}. Commands return confirmed state. Never show success before confirmation.

- connect, state: return current state. Get tab with chrome.tabs.query({active:true,currentWindow:true}).
- catalog: bundled array of {family,category,variants}. Search locally. Choose a result to swap, typing alone does nothing.
- pick {mode:'source'|'destination'}: source picker in accessible frames; destination picker in origin document only. Hover shows visible font name, pointer cursor and a subtle highlight in both modes. A temporary on-page eyedropper badge identifies picking mode. Picking, Escape, Cancel and Undo remove the badge and restore the website cursor and highlight styles. Escape cancels picking in all permitted frames. cancel exits.
- preview {destination:{kind:'google'|'page',family},scope:'all'}: loads and immediately applies. No Apply step.
- select {ruleId,frameId}: select existing pair for editing.
- remove {ruleId,frameId}: remove one pair and preserve the others.
- undo: restore all pairs in all accessible frames.

State includes {tabId,frameId,url,source,destination,selection,count,pageFonts,active,applied,picking,status,error,warnings,rules:[{id,frameId,source,destination:{kind,family},count}]}. Source is the original CSS family. Destination is null for a new source. Existing pairs persist when picking another source. Choosing a destination for the same source replaces that pair. Rules aggregate accessible frames.

Listen for STATE_CHANGED {tabId,state}. Reconnect on tabs.onActivated and tabs.onUpdated complete. Ignore stale responses and updates for other tabs. Show state.error and command failures; preserve current swaps on failure. Loading blocks duplicate choices. Use textContent for dynamic text.

The empty panel uses the same Pick from page source row, with no separate intro screen. Clicking the idle row starts picking. Escape stops picking, restores the website cursor, and leaves that row static and clickable. Undo all or removing the last swap returns to that same row. Starting a source pick opens a pending accordion with a blinking 2px dashed Pick from page source label and eyedropper icon. Its instructions and Cancel control stay inside that row. Adding another font uses the same pending accordion. Loading and errors belong to the active accordion. While loading a font, show a small spinner beside the loading message, including page-picked replacements. Clear it on success or failure and keep it static for reduced motion. After picking, show a compact source → Choose font row. Its open editor contains Search Google Fonts, an eyedropper Pick from page action, and the results separated by a divider. These belong to the row, with no numbered cards or repeated source box. Choosing a result applies immediately and collapses the row. Only one row opens at a time. Opening, closing and switching rows preserves all applied swaps. A separate × removes a pair. One unfinished row can be closed, reopened or discarded without affecting existing swaps. Pick another font and Undo all remain available. No Apply, Compare, scope radios, category filters, snippets, or metadata. Short picker hint with Cancel. Warnings may use a small disclosure. Stack font labels when they do not fit, with no ellipsis. Use 8px rounded corners and a blue border-only blink every 0.8 seconds, alternating clearly between full brightness and 10% opacity. Keep text and the Lucide pipette icon steady, and use that same icon in both pickers and the page badge. Disable border animation for reduced motion. Keep 240px and 320px layout, light/dark themes, focus styles and keyboard search navigation. Arrow keys browse; Enter or click commits. Focus returns to the changed row after choosing. No all-caps subtitles or em dashes.

The source, apply, compare, element scope and sample actions remain internal compatibility APIs. They are not part of this simplified UI.

The floating build reuses these controls in a closed shadow root on the main page, with no iframe or page-width changes. Start 16px from the top-right, at 320px wide or the available viewport width. The header has an SVG drag grip and close button. Dragging, focused-grip arrow keys, viewport resize and content expansion keep the panel within reach. Closing cancels picking and preserves swaps. The toolbar reopens the same panel. Exclude its text and controls from picking, hover detection, font matching and mutation scanning. Keep the same loading, error, light/dark and reduced-motion behavior. Only the floating manifest accepts panel commands from its main-frame content script, and the worker takes the tab ID from the authenticated sender.
