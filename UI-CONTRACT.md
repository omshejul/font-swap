# Side panel contract

Plain HTML/CSS/JavaScript. No inline scripts, remote JavaScript, or framework. UI files are extension/sidepanel.html, .css and .js.

Send {type:'PANEL',action,tabId,...payload} through chrome.runtime.sendMessage. Response is {ok:true,state?,catalog?} or {ok:false,error}. Commands return confirmed state. Never show success before confirmation.

- connect, state: return current state. Get tab with chrome.tabs.query({active:true,currentWindow:true}).
- catalog: bundled array of {family,category,variants}. Search locally. Choose a result to swap, typing alone does nothing.
- pick {mode:'source'|'destination'}: source picker in accessible frames; destination picker in origin document only. Hover shows visible font name, pointer cursor and a subtle highlight in both modes. A temporary on-page eyedropper badge identifies picking mode. Picking, Escape, Cancel and Undo remove the badge and restore the website cursor and highlight styles. Escape cancels picking in all permitted frames. cancel exits.
- preview {destination:{kind:'google'|'page',family},scope:'all'}: loads and immediately applies. No Apply step.
- select {ruleId,frameId}: select existing pair for editing.
- remove {ruleId,frameId}: remove one pair and preserve the others.
- tag-options {ruleId,frameId}: return eligible HTML tags and element counts from the existing page scan.
- tags {ruleId,frameId,tags:null|[tag,...]}: narrow one pair to selected tags, including nested text with the same original family. Null means all tags; an empty array applies nowhere. Keep other pairs and the current editor unchanged.
- undo: restore all pairs in all accessible frames.

State includes {tabId,frameId,url,source,destination,selection,count,pageFonts,active,applied,picking,status,error,warnings,rules:[{id,frameId,source,destination:{kind,family},tags,count}]}. Source is the original CSS family. Destination is null for a new source. Existing pairs persist when picking another source. Choosing a destination for the same source replaces that pair. Rules aggregate accessible frames.

Listen for STATE_CHANGED {tabId,state}. Reconnect on tabs.onActivated and tabs.onUpdated complete. Ignore stale responses and updates for other tabs. Show state.error and command failures; preserve current swaps on failure. Loading blocks duplicate choices. Use textContent for dynamic text.

The empty panel uses the same Pick from page source row, with no separate intro screen. Clicking the idle row starts picking. Escape stops picking, restores the website cursor, and leaves that row static and clickable. Undo all or removing the last swap returns to that same row. Starting a source pick opens a pending accordion with a blinking 2px dashed Pick from page source label and eyedropper icon. Its instructions and Cancel control appear only on the webpage in an isolated card, with a pipette icon and Escape hint. Adding another font uses the same pending accordion. Loading and errors belong to the active accordion. While loading a font, show a small spinner beside the loading message, including page-picked replacements. Clear it on success or failure and keep it static for reduced motion. After picking, show a compact source → Choose font row. Its open editor contains Search Google Fonts, an eyedropper Pick from page action, and the results separated by a divider. These belong to the row, with no numbered cards or repeated source box. Choosing a result applies immediately and collapses the row. Only one row opens at a time. Opening, closing and switching rows preserves all applied swaps. A separate × removes a pair. One unfinished row can be closed, reopened or discarded without affecting existing swaps. Pick another font and Undo all remain available. No Apply, Compare, scope radios, category filters, snippets, or metadata. Keep picking guidance out of the accordion. Do not show Notes or the CSS-family/fallback explanation. Stack font labels when they do not fit, with no ellipsis. Use 8px rounded corners and a blue border-only blink every 2 seconds, alternating clearly between full brightness and 10% opacity. Keep text and the Lucide pipette icon steady, and use that same icon in both pickers and the page badge. Disable border animation for reduced motion. Keep 240px and 320px layout, light/dark themes, focus styles and keyboard search navigation. Arrow keys browse; Enter or click commits. Keyboard selection returns visible focus to the changed row. Pointer selection and collapse do not force row focus. No all-caps subtitles or em dashes.

Each applied pair has a small funnel icon beside its chevron and remove button. It opens an anchored Apply to tags popover with All tags reset, a Find tags search and native multi-select checkboxes showing HTML tag, friendly name and count. No matching-elements or live-updates footer. Default is unrestricted; filtered pairs show a compact blue tag summary. Keep the popover open and checkbox focus stable while changes apply. Escape and outside clicks dismiss it. It fits both layouts at 240px and 320px, avoids scroll clipping and uses the existing dark/light colors. Only the chosen source family changes inside selected tags, including nested text and shadow DOM; icon protection remains intact. Destination edits preserve tags. Available choices use the existing scan without scanning again on popover interaction.

The source, apply, compare, element scope and sample actions remain internal compatibility APIs. They are not part of this simplified UI.

Both layouts use a compact title bar separated from the body by a subtle divider. In dark mode its background is charcoal #303134; light mode uses the equivalent light surface. Keep the brand and actions on one row, with a 22px icon, 15px title, 26px icon controls and 8px by 10px header padding. The floating panel has 12px outer corners.

While a replacement font loads, show one readable spinner and loading label inside its accordion, without dimming the whole panel. A matching isolated status badge appears at the bottom of the main webpage until the font applies or fails. It never intercepts page input and is excluded from font detection and mutation scanning. Reduced motion keeps both spinners static. Preserve the current preview until the replacement succeeds.

The floating mode reuses these controls in a closed shadow root on the main page, with no iframe or page-width changes. Start 16px from the top-right, at 320px wide or the available viewport width. The header has an SVG drag grip and close button. Dragging, focused-grip arrow keys, viewport resize and content expansion keep the panel within reach. Closing cancels picking and preserves swaps. The toolbar reopens the same panel. Exclude its text and controls from picking, hover detection, font matching and mutation scanning. Keep the same loading, error, light/dark and reduced-motion behavior. The worker accepts panel commands from its authenticated main-frame content script and takes the tab ID from that sender. Both modes share one manifest, toolbar action and packaged ZIP. A header icon describes the destination mode: Float on page in the sidebar, Dock to side panel in the floating panel. Switching cancels picking and preserves active swaps. Remember the last successfully chosen mode in local extension storage. New installs use the side panel. Show one mode at a time in the active window. No Notes disclosure.

## Saved site pairs

Below Pick another font, show one native checkbox, Remember for this site, when a main-page pair exists or the site is remembered. Both layouts share the same control. Request optional access to that host on checking. Save only origin, main-page family pairs and optional HTML tag names locally, no text or element references. Restore on future visits without opening controls, preserving each tag filter. Older saved pairs default to all tags. Edits and removals update saved pairs; Undo all clears them. Unchecking forgets pairs but keeps the current page preview. Permission denial leaves the checkbox off and shows the error beside the controls.

## Picking attention

Each source or replacement picking session fades the blue edge glow to 50% of its former peak opacity over 500ms with ease-in-out, then holds it throughout picking. Keep the page center clear. The bottom dialogue retains one blue fill and outline pulse, starting 100ms later and lasting 400ms. The viewport effect sits below the floating panel. Only extension-owned opacity animates, with isolated styles and no pointer interception. Reduced motion uses a static half-opacity glow throughout picking and one 500ms static dialogue outline. Selection, Escape, Cancel and panel closure stop picking immediately, clear its timers and dialogue animations, and fade the remaining glow out over 200ms with ease-in-out before removal. Reduced motion removes it immediately. Repeated activation resumes from the current opacity without stacking overlays or letting an earlier cleanup remove the new effect. Hover and UI updates do not retrigger the effect, and its nodes are excluded from detection and mutation scanning. The dashed source border stays fully bright for 80% of each 2-second cycle, with a brief dip to 10% opacity and return. The empty source row uses one divider and aligned wrapped labels; Google Fonts has equal 12px top and bottom spacing in both layouts. Font search results use a thin neutral scrollbar with a transparent track.
